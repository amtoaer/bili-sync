# 下载番剧（动漫）

bili-sync 支持从 B 站番剧播放链接添加单集或整季订阅，沿用已有的下载路径、画质、账号凭据和定时下载设置。

## 添加番剧

1. 按照[快速开始](./quick-start.md)启动 bili-sync，并在管理页完成账号登录和下载设置。
2. 打开「视频源」，切换到「番剧」页签，点击「添加番剧」。
3. 粘贴播放链接，例如 `https://www.bilibili.com/bangumi/play/ep32367`，也可以直接输入 `ep32367`。
   停止输入后，下方会自动展示番剧海报、名称、全季累计播放量、追番人数、评分和更新信息；分集链接还会显示对应集名。缺失的统计不会显示为零，获取失败时可以点击「重试」。预览只用于确认信息，不会创建订阅。
4. 默认只下载链接对应的一集。勾选「下载整季并持续同步新集」会添加该集所属季的全部正片；输入 `ss1733` 或对应的整季播放链接则始终下载整季。
5. 填写 bili-sync 所在设备上的保存路径并添加。Windows 示例：`F:\Videos\罗小黑战记`；Docker 示例：`/videos/罗小黑战记`（需先映射对应目录）。
6. 在「番剧」页签中找到新增条目，点击编辑，打开「启用此视频源」并保存。然后在首页执行下载，或等待下一次定时任务。

`ep32367` 对应《罗小黑战记》第 8 话《深山》，其所属季为 `ss1733`。同一链接选择单集或整季，会得到不同的订阅范围。整季订阅只包含该季主分集列表，不自动添加其它季或额外花絮。

## 下载与管理

- 「合集」与「番剧」在视频源中分开显示，已有订阅会自动归入对应页签，无需重新添加。
- 番剧在「番剧」页签中标注「番剧 · 单集」或「番剧 · 整季」，点击名称可打开 B 站播放页。
- 下载任务自动选择当前账号可获取、且符合画质设置的视频和音频流，使用 FFmpeg 合并。
- 整季订阅在后续扫描中查找新集；已完成的分集沿用数据库状态，不会在每轮扫描中重复下载。
- 与其它视频源一样，可以编辑保存路径、设置筛选规则和独立画质，或重置失败任务后重试。
- 同一集如果分别添加到单集和整季订阅，会按两个视频源分别管理。仅需一份文件时，请只保留所需范围的订阅。

## 账号权限与失败提示

会员、付费、地区限制和可选画质取决于当前账号与 B 站接口返回结果。需要大会员或购买的内容，应使用具有相应观看权限的账号。程序不会把试看片段当作完整分集下载；受 DRM 保护的流会明确报错。

当前支持 DASH 音视频流和单段混合流。如果接口只返回多段 FLV，会提示暂不支持，避免仅保存第一段后误报完成。

若日志提示无可用流，请检查登录状态、该集能否在同一网络和账号下完整播放，以及最小画质是否超过该账号可用画质。修改凭据或设置后，可重置相应任务并再次执行下载。

## API 示例

向 `POST /api/video-sources/bangumi` 发送以下 JSON 可添加单集订阅（鉴权方式与现有 API 一致）：

```json
{
  "url": "https://www.bilibili.com/bangumi/play/ep32367",
  "path": "/videos/罗小黑战记",
  "whole_season": false
}
```

将 `whole_season` 改为 `true` 可订阅该集所属整季。`ss` 输入始终对应整季。新增条目默认禁用，后续通过现有 `collections` 视频源管理接口启用和管理。
